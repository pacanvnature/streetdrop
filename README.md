# StreetDrop 👟

**StreetDrop** — учебный проект интернет-магазина уличной одежды и обуви.

## 🛍️ О проекте

StreetDrop — веб-приложение, созданное в рамках учебной практики. Проект демонстрирует работу интернет-магазина с каталогом товаров и базой данных.

## ✨ Возможности

- Просмотр каталога товаров
- Отображение изображений и цен товаров
- Работа с вариантами товаров
- Корзина покупок
- Изменение количества товаров в корзине
- Хранение данных с помощью Supabase

## 🛠️ Технологии

- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL

## 🚀 Назначение проекта

Проект разработан в учебных целях для получения практических навыков создания веб-приложений, работы с базами данных и разработки пользовательского интерфейса интернет-магазина.

## 🔐 Конфигурация

Для подключения к Supabase необходимо настроить переменные окружения в файле `.env.local`:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

**Важно:** не публикуйте секретные ключи и файл `.env.local` в открытом репозитории.

## 📌 Статус проекта

Учебный проект в разработке.
